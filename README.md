# 30DayMapChallenge 2026 🗺️

One map a day throughout November.

This year, I’m focusing on learning through mapping tutorials:
understanding the workflows, exploring different tools and adapting
the results with my own ideas.

The collection includes maps made with Python, R, QGIS and other
geospatial tools. Each project credits its data sources and the
tutorials that inspired it.

## Repository structure

Each day has its own folder containing the relevant code,
documentation and map previews.

Large datasets, local environments and temporary files are excluded.
Individual project READMEs explain any required downloads or local files.
